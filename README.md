# AI Ban Simulator — Privacy Policy

*Last updated: October 11, 2026*

AI Ban Simulator ("the game") is an offline Android game.

**The game collects no data.** It has no accounts, no ads and no analytics, and it does not ask for the internet permission, so it cannot send anything anywhere.

**What stays on your phone.** The game remembers which endings you have found, which made-up AI name you picked last and the language you chose, so they are there the next time you open it. This is kept in the game's own storage on your device and is removed when you uninstall the game (or clear its data in Android's settings).

**Children.** The game is not directed at children.

**Changes.** If this policy changes, the new version will be posted on this page.

**Contact.** sublueai@gmail.com

# AI 封号模拟器 — 隐私政策

*最近更新：2026 年 10 月 11 日*

《AI 封号模拟器》（下称“本游戏”）是一个离线的安卓游戏。

**本游戏不收集任何数据。** 没有账号，没有广告，没有统计分析；它甚至没有申请联网权限，所以无法向任何地方发送任何内容。

**留在你手机上的内容。** 本游戏会记住你已经解锁了哪些结局、上次选的是哪个虚构的 AI 名字，以及你选的语言，方便下次打开时还在。这些只保存在你设备上本游戏自己的存储里，卸载游戏（或在系统设置里清除它的数据）后即被删除。

**儿童。** 本游戏不面向儿童。

**变更。** 本政策如有变更，新版本会发布在本页面。

**联系方式。** sublueai@gmail.com
